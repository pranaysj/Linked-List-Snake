# 🐍 Snake Game Reimagined (C++ & SFML)

Recreating the **classic Snake Game** from Nokia 3310 with a modern touch using **C++**, **SFML**, and **Object-Oriented Programming**.

---

## 🚀 Overview

This project brings together **nostalgia** and **modern coding** by combining:
- Real-time rendering and input handling
- Custom mechanics using **Singly** and **Doubly Linked Lists**
- Dynamic gameplay with multiple levels

---

## ✨ Features

- 🖥️ Built in **Visual Studio 2022 (64-bit)**
- 🔧 Developed using **C++** and **OOP principles**
- 🎨 Rendered with **SFML** graphics
- 🎮 **Two unique levels**:
  - Level 1: Snake built using **Singly Linked List**
  - Level 2: Snake built using **Doubly Linked List** for improved control

---

## 🔑 Key Learnings

- ✅ Applied **Linked List** structures in game logic
- 🧠 Mastered **dynamic memory management**
- 🕹️ Handled **real-time input** and rendering with **SFML**
- 💥 Implemented **collision detection** and smooth gameplay flow
